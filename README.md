# 🎬 BOOK MY SHOW – Movie Booking & Revenue Analytics Dashboard

## 📌 Project Overview

The **BookMyShow Movie Booking & Revenue Analytics Dashboard** is an interactive business intelligence project developed using Microsoft Power BI.

The project focuses on analyzing movie booking performance, ticket sales, revenue generation, cancellation trends, movie popularity, and theatre performance.

The dashboard transforms booking data into meaningful business insights through interactive charts, KPI cards, and screen-format filters.

## 🎯 Project Objectives

- Analyze total movie bookings and ticket sales.
- Monitor booking success and cancellation rates.
- Understand revenue distribution across screen formats.
- Identify popular movies based on bookings.
- Analyze genre-wise booking distribution.
- Compare revenue performance across different cities.
- Evaluate overall ticket pricing and revenue trends.
